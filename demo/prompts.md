# Pantry demo prompts

Run these in order in Claude Code, in the Pantry folder, one at a time. Wait for each to finish
before sending the next.

1. Read the README and set up the project. Plain HTML, CSS and JavaScript, and Node's built-in test runner for the logic.

2. Add a form with name, quantity and expiry date. Save the items in localStorage so they stay after a refresh.

3. Show the items sorted by expiry date, soonest first.

4. Highlight anything expiring in the next 3 days, and show the count at the top of the page.

5. Add a button to mark an item as used up. It should disappear from the list.

6. Put the date and sorting logic in its own file and add tests for it. Make sure they pass.

7. Check that the layout works on a phone screen.

8. Add a short section to the README on how to run the app and the tests.
